# Homework 3: FrozenLake

This assignment studies tabular reinforcement learning in Gymnasium's `FrozenLake-v1` environment under deterministic and slippery transition dynamics.

## Contents

- [`frozenlake.ipynb`](frozenlake.ipynb): implementation, experiments, and discussion
- `Hw3 report.pdf`: submitted report
- `res*.png`: results from the first experiment
- `slipperyn*.png`: results from slippery-environment experiments
- `Hw3.zip` in the repository root: original submission archive

## Run

From the repository root, install the base environment and open the notebook:

```bash
pip install -r requirements.txt
jupyter lab Hw3/frozenlake.ipynb
```

The notebook was created with Python 3.12 and uses NumPy, Matplotlib, and Gymnasium.
